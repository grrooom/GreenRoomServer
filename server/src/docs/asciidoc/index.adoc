== 응답형식

=== 공통 응답 형식

[source, json]
----
HTTP/1.1 {HTTP STATUS CODE} {HTTP STATUS}
Content-Type: application/json
{
  "status":  "http status" ,
  "code":  "custom status code",
  "data": "data"
}

----

=== 성공 응답

요청이 성공했을 경우 아래의 Http Status를  반환합니다.

[cols="5,5,10,6", options="header"]
|===
| Http Status Code | Http Status | 비고 | Response Body
| 200 | OK | 요청에 성공  | O
| 201 | CREATED | resource 생성 | O
| 204 | NO CONTENT |요청에 성공했으나 반환할 응답값이 없음 | X
|===

=== 응답 예시

==== 1. Response Body가 없는 경우

[source, json]
----
HTTP/1.1 204 NO CONTENT
----

==== 2. 응답 data가 없는 경우
[source, json]
----
HTTP/1.1 201 CREATED
Content-Type: application/json
{
  "status": "CREATED", // 예시
  "code": "A001", //예시
  "data": null
}
----

==== 3. 응답 data가 있는 경우 예시
[source, json]
----
HTTP/1.1 200 OK
Content-Type: application/json
{
  "status": "OK", //예시
  "code": "A000", //예시
  "data": {
    "id": 123,
    "name": "example"
  }
}
----

== 실패 응답

[cols="2,4,4,4,8", options="header"]
|===
| 구분 |Http Status Code | Http Status  | custom error code | 비고
| 공통 | 500 | INTERNAL_SERVER_ERROR | D000 | 서버 측에서 처리하지 못한 예외가 발생하면 모든 api 요청에 대해 공통적으로 반환됨.
| 공통 | 400 | BAD_REQUEST | C023 | API 요청에서 요구되는 request body의 조건을 만족하지 못했을 경우 공통적으로 반환됨. (ex. email 형식 불일치, 필수 field 존재x)
| 공통 | 404 | NOT FOUND | C001 | access token에 포함된 user 정보를 서버에서 찾지 못하는 경우 공통적으로 반환됨.
| JWT | 401 | UNAUTHORIZED | C004 |  Access Token이 만료됨
| JWT | 401 | UNAUTHORIZED | C006 |  Access Token을 header에서 찾을 수 없음
| JWT | 401 | UNAUTHORIZED | C008 |  부적절한 Access token이 전달됨
|===

== 이미지 파일 요청

=== 썸네일 요청

전달된 이미지 파일 url로 요청.

url 예시 : https://{cdn-url}/local/user/f1c5ce09-476f-4a17-8bbe-889cc92bee72r3r2-test2.jpeg

==== Query Parameter

[cols="4,4,4,4,4", options="header"]
|===
| param | description  | type | required | 비고
| w | 가로 크기 | int | true |
| h | 세로 크기 | int | true |
| q | 이미지 quality | int | false (default : 80) | 0-100 (%)
| f | 반환 이미지 format | string | false (default : jpg) | jpg, png, jpeg
|===

=== **4. 이메일 인증**
회원가입 이전에 사용자의 이메일 주소를 검증하기 위해 사용됩니다. +
